# natsci-modern-campus-theme-2025
This project houses the College of Natural Science Modern Campus theme. This is an attempt to consolidate styles from [ Natsci Mura Cssgrid V1 OmniCMS ](https://gitlab.msu.edu/natsciwebteam/natsci-mura-cssgrid_v1_OmniCMS) and to better document the code for end users.
